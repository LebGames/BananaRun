# Banana Run website — LEBGAMES GitHub Pages

Target repository: https://github.com/lebgames/BananaRun
Published address: https://lebgames.github.io/BananaRun/

Upload the CONTENTS of this folder into the repository root (index.html, style.css, script.js, assets/). Do not nest them in another directory. In repository Settings > Pages, select Deploy from a branch, main, /(root), unless an existing workflow handles deployment.

All website asset references are relative, so they work from the /BananaRun/ project subpath.

The download and support placeholders are intentionally unchanged pending official verified URLs.

This package does not contain app-ads.txt and does not alter the advertising file on any existing domain.
